सरस्वती शिशु मंदिर मोबाइल ऐप आचार्यों, प्रधानाचार्यों, संकुल प्रभारियों एवं अभिभावकों को स्मार्टफोन पर सरल, तीव्र और सुरक्षित अनुभव प्रदान करता है:

- 🏛️ **कार्यालय प्रशासन व संकुल पटल**: शुल्क संग्रहण, डिजिटल रसीदें, छात्र प्रवेश, टी.सी. निर्गमन एवं UDISE+ डेटा नियंत्रण।
- 👨‍🏫 **आचार्य पटल**: मात्र ३० सेकंड में कक्षावार हाजिरी, गृहकार्य डायरी प्रेषण, अंक प्रविष्टि एवं मासिक वेतन पर्ची।
- 👨‍👩‍👧 **छात्र एवं अभिभावक पटल**: सजीव उपस्थिति स्थिति, डिजिटल शुल्क भुगतान इतिहास, NEP 2020 ३६०° समग्र प्रगति पत्र (HPC) एवं परीक्षा प्रवेश पत्र।
- 🔙 **हार्डवेयर बैक बटन सुरक्षा**: आकस्मिक ऐप बंद होने से रोकथाम — पॉप-अप स्वतः बंद होते हैं एवं मुख्य स्क्रीन पर दोहरे टैप पर ही ऐप बंद होता है।
- 📷 **स्मार्ट कैमरा स्कैनर**: छात्र प्रवेश एवं परिचय पत्र हेतु उच्च-गुणवत्ता कैमरा फ़ोटो व स्वतः इमेज कंप्रेशन।
- ⚡ **शून्य-विलंब शुरुआत (0ms Launch)**: कमजोर २जी/३जी नेटवर्क अथवा हवाई मोड में भी ऐप बिना सफ़ेद स्क्रीन के तत्काल खुलता है।
- 🔔 **इन-ऐप स्वतः संस्करण अद्यतन**: नया सुरक्षा पैच या शैक्षणिक मॉड्यूल आने पर ऐप के भीतर ही १-क्लिक अपडेट की सुविधा।

## 📥 अधिष्ठापन मार्गदर्शिका (How to Install APK)

1. ऊपर दिए गए **[नवीनतम एपीके डाउनलोड लिंक](https://github.com/Paras65/ssm-app-apk/releases/latest)** पर टैप करें।
2. Assets सूची में से **`ssm-school-erp.apk`** पर टैप करके डाउनलोड करें।
3. **अज्ञात स्रोत अनुमति (Unknown Sources)**: यदि फ़ोन *"अज्ञात स्रोतों से ऐप इंस्टॉल करें"* पूछे, तो ब्राउज़र अथवा फ़ाइल प्रबंधक को अनुमति दें।
4. **Google Play Protect**: यदि सुरक्षा स्क्रीन पर चेतावनी दिखाई दे, तो घबराएं नहीं। **"More details" (अधिक विवरण)** पर टैप करें और **"Install anyway" (फिर भी इंस्टॉल करें)** चुनें।
5. **सफलतापूर्वक उपयोग प्रारंभ करें**: होम स्क्रीन पर भगवा कमल (`🪷`) आइकन वाले **"सरस्वती शिशु मंदिर"** ऐप को खोलें।
